# Kairos Tool Prompt Sources

Verbatim copies from commit `5f34b423`, under
`packages/kairoscode/src/tool/*.txt`.

They are source material for Clamp's model-facing tool descriptions. They are
not wired into the current runtime because some describe parameters and
behavior that Clamp has not implemented yet (for example paging in `read` and
format conversion in `web_fetch`).
