# Atendimento Ao Cliente

Esta feature descreve a Anna aplicada a atendimento: copiloto dos atendentes do Comercial e canal direto para clientes/futuros alunos que querem se matricular.

Implementacao atual:

- `persona.ts`: identidade centralizada `ANNA` (saudacao, dicas e mensagens) usada na interface assistiva.

Cenarios comuns:

- atendimento via web ou WhatsApp;
- matricula conversacional de futuros alunos (novo "Matricule-se" via NLP);
- apoio ao atendente do Comercial: consulta de cursos, candidatos e inscricoes;
- suporte com RAG, CRM, ERP, agenda e pagamentos.
